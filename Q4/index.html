Domain Filter Validator

Check if your domain filter expressions are valid

How it works:

Basic format: field operator value

Valid operators: = != < > % notin

Values: Numbers, "quoted strings", or [list, items]

Logic: Use AND / OR to combine conditions

Grouping: Use ( ) to group expressions

Valid Examples:

(status = "paid") AND (amount > 1000)

(status in ["pending","paid"])

amount != 500
